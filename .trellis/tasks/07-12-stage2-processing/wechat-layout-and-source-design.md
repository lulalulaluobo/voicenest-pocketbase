# 公众号阅读排版与原文改写设计

**状态**：已获用户确认，待审阅  
**目标**：改善公众号草稿的阅读排版；让二次改写基于 ASR 原文，把提示词模板集中到设置页管理，并在发布前预览实际排版。

## 已确认需求

- 公众号草稿采用简洁的“公众号阅读版”排版，而非浏览器默认 Markdown 样式。
- 公众号二次改写只使用 ASR 原文 `transcript`，不使用已由 LLM 整理过的个人笔记 `summary`。
- 没有 `transcript` 的旧录音禁止生成公众号文章，并提示用户先重新转写；不得回退到 `summary`。
- 三个公众号提示词模板移至设置页编辑并持久化；公众号编辑页只提供模板下拉选择，不提供提示词文本编辑。
- 发布前可打开预览弹窗，确认与实际草稿一致的公众号排版后再推送草稿箱。

## 数据流

```text
录音 → ASR transcript → 个人笔记 LLM → summary → Obsidian
                  └─ 用户进入公众号编辑页
                       → 选择设置页管理的模板
                       → LLM 基于 transcript 生成公众号 Markdown
                       → 人工编辑 → 预览 Worker 渲染的公众号阅读 HTML → 确认 → 草稿箱
```

`summary` 继续仅代表个人笔记；`wechatTitle`、`wechatMarkdown` 继续只代表公众号文章。

## Worker 排版

修改 `renderWechatHtml`，仍使用 `markdown-it` 且禁用原始 HTML。为下列元素输出固定内联样式，确保微信公众号编辑器保存后样式稳定：

- 正文：16px 字号、1.9 行高、深灰文字、连续段落间距。
- 标题：`h1` 用于文章内主标题；`h2`、`h3` 用左侧强调线和分级间距。
- 列表：`ul`、`ol` 提供统一缩进、行高和上下边距；每个 `li` 单独留出间距，避免默认样式造成的空白项目或编号错位。
- 强调与链接：粗体使用正文强调色；链接使用微信蓝并保留可辨识的下划线。
- 引用、分割线、图片和代码块：使用克制的浅色背景/边线，不引入卡片化或装饰性色块。

不新增前端富文本编辑器，也不在客户端拼接 HTML；所有公众号 HTML 仍只由 Worker 生成。

## 发布前预览

- Worker 新增受现有 Cloudflare Access 与 CORS 保护的 `POST /preview`，请求只接受非空的 `title` 和 `markdown`，复用 `renderWechatHtml`，返回 `{ title, html }`。
- PWA 新增 `previewWechatDraft` 客户端方法，沿用现有 Worker URL、`credentials: 'include'` 和错误归一化逻辑。
- 公众号编辑页在“发布到草稿箱”前提供“预览排版”按钮；成功时用带 `sandbox` 的 iframe 弹窗展示返回的完整文章 HTML。iframe 的 `srcDoc` 仅使用 Worker 的转义后渲染结果。
- 用户可关闭预览继续修改；预览不会创建或更新草稿，不写入公众号发布状态。确认后仍由现有“发布到草稿箱”按钮显式提交。

## 页面调整

### 设置页

在“公众号草稿箱”折叠区域，保留启用开关、Worker 地址、连接测试和重新授权；在它们下方展示三个固定模板（观点随笔、知识分享、日常记录）的名称及 textarea。模板输入失焦即保存，备份导入导出沿用现有 `wechatPromptTemplates` 字段。

### 公众号编辑页

- 参考区标题改为“ASR 原文参考”，只读显示 `transcript`。
- `transcript` 为空时显示“请先重新转写，再生成公众号文章”，并隐藏/禁用生成动作。
- 保留原生 select 作为模板筛选器、生成按钮、公众号标题/正文编辑、“预览排版”和发布按钮。
- 删除页面中的提示词 textarea、模板本地保存逻辑和相关状态；生成时以当前 select 对应的设置页模板 prompt 调用现有 `rewriteWechatArticle`。

## 错误与验收

- Worker Markdown 测试覆盖正文、标题、无序/有序列表、引用、分割线、链接和原始 HTML 转义，断言输出含预期的内联样式；Worker 路由测试覆盖 `/preview` 不调用微信草稿 API。
- 前端测试覆盖没有 ASR 原文时不调用改写 LLM 的守卫逻辑；改写请求中的用户内容必须包含原文而非 `summary`。
- 设置页模板仍使用既有 localStorage 键，用户编辑后刷新页面和备份导入后保持。
- 前端与 Worker 的测试、类型检查和构建均需通过；Worker 变更完成后重新部署，随后部署 Vercel。

## 明确不做

- 不增加公众号样式主题切换、Markdown 实时预览、富文本编辑器、图片图床、自动发布或草稿管理列表。
