# 全量数据备份与恢复

## 目标

在设置页提供单个 ZIP 文件的全量数据备份与恢复，用于迁移到 Android APK 前保存并恢复 VoiceNest 的所有本地数据。

## 已确认需求

- 导出与导入一个 `voicenest-backup-YYYYMMDD.zip` 文件。
- 备份包含全部 `vn_*` 配置：ASR/LLM API Key、Obsidian Token、分类与提示词、公众号配置与提示词、主题、自动处理和保留策略。
- 备份包含全部录音元数据、ASR 转写、LLM 整理文章、公众号草稿状态与原始音频分片。
- 备份文件明文包含凭据，仅供个人离线保存；界面必须明确提示这一点。
- 导入时先校验文件；只有校验完成且用户二次确认后，才清空本地录音库和 `vn_*` 配置并完整恢复备份。
- 不支持合并导入；目标设备现有 VoiceNest 数据会被备份完全替换。

## 验收标准

1. 导出的 ZIP 可在同一浏览器或新的 Android WebView 中导入。
2. 导入后配置、凭据、分类、提示词、录音、音频、转写、整理文章和公众号草稿状态与导出前一致。
3. 损坏、版本不支持或缺少音频文件的备份导入失败时，原本本地数据保持不变。
4. 用户取消二次确认时，原本本地数据保持不变。
5. 自动化测试覆盖完整往返、无音频记录、无效备份与清库恢复。

## 非目标

- 云端备份、加密、增量备份、多设备同步。
- 将录音转码为其他格式。
- 合并两个备份或恢复已删除的单条记录。
