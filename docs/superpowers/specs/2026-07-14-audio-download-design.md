# 音频下载设计

## 目标

在录音列表中为已完成 LLM 整理、且本地音频分片仍存在的录音提供下载按钮。下载文件名使用 LLM 生成的笔记标题，并保留音频实际格式的扩展名。

## 已确认决策

- 复用 `Recording.localTitle`：现有处理流程已在 LLM 整理成功后将返回的 `title` 写入该字段，不新增重复字段或数据库迁移。
- 仅当录音已有整理结果且音频未被清理时允许下载。
- 文件名中的非法字符替换为安全字符；扩展名根据 `mimeType` 选择。

## 实现边界

`RecordingCard` 新增“下载音频”操作：读取该录音现有的 IndexedDB 分片，按顺序合成为 Blob，使用浏览器原生 Object URL 与临时 `<a download>` 触发下载，并在完成后释放 URL。

音频已因保留策略清理、没有分片或尚未完成 LLM 整理时，按钮禁用并提供对应原因。下载过程不改变录音、分片或处理状态。

## 验证

- 为文件名生成逻辑添加最小单元测试，覆盖实际 MIME 扩展名与非法字符替换。
- 执行 `npm test` 与 `npm run build`。
